# 优化及效率工具

## 图吧工具箱
下载地址 : [https://tbtol.cn/](https://tbtol.cn/)
新电脑验机必备。检查新电脑的电池使用情况、烤机时的 CPU GPU 功耗、屏幕是否有坏点、键盘连接情况等。
并且包含好几个功能强大的工具如 everything、 geekuninstaller 等。小工具多且专业，不需要再挨个下载其他软件。

## Everything
下载地址 : [https://www.voidtools.com/](https://www.voidtools.com/)
一个本地搜索工具。搜索速度远高于 windows 资源管理器自带的搜索。在寻找未被完全卸载的软件、存放在不知道哪里的文档时十分好用。

## Geekuninstaller
下载地址 : [https://geekuninstaller.com/](https://geekuninstaller.com/)
卸载工具。小巧便携，即开即用。卸载无残留，并且支持支持卸载 Windows 应用如 Mircosoft Store 等。

## FluentCleaner
下载地址 : [https://github.com/builtbybel/FluentCleaner](https://github.com/builtbybel/FluentCleaner)
磁盘清理工具。开源免费，界面清爽无广告，清理功能强。

## Rammap
下载地址 : [https://learn.microsoft.com/zh-cn/sysinternals/downloads/rammap](https://learn.microsoft.com/zh-cn/sysinternals/downloads/rammap)
内存管理工具。内存释放效果显著，但不要在重要软件运行时使用。

## 卡巴斯基
下载地址 : [https://www.kaspersky.com.cn/](https://www.kaspersky.com.cn/)
杀毒软件。界面清爽不存在 360 杀毒的流氓操作，免费版无防火墙。

# 美化及个性化软件
## 小狼毫 (mac Rime)
下载地址 : [https://rime.im/](https://rime.im/)
Rime 是全平台的输入法软件， windows 上称为小狼毫。
特点是安装后仅在本地运行，不会接入互联网，没有广告，且可以高度自定义。打开配置文件可以更改输入法的外观、双拼全拼切换、特殊字符输入等。配置难度较高，无图形化界面。

## TranslucentTB 
下载地址 : [https://translucenttb.net/](https://translucenttb.net/) ( 也可在微软商店下载 )
可以使任务栏透明。日常内存占用小。

## Nexus
下载地址 : [https://winstep.net.cn/](https://winstep.net.cn/)
桌面美化工具。可以让 windows 带有类似于 Mac OS 的 底部 Dock 栏。可以修改位置、透明度等（在最小化等细节处理不如原生 Mac OS）。同样占用小不吃电脑配置。

## Autohidedesktopicons
下载地址 : [https://www.softwareok.com/?seite=microsoft/autohidedesktopicons](https://www.softwareok.com/?seite=microsoft/autohidedesktopicons)
可以自动隐藏桌面（任务栏也可）。
